## 🔄 WORKFLOW

### Development Workflow
```
1. Edit code in app/ directory
2. API auto-reloads (uvicorn --reload)
3. Test changes with test_api.py
4. Verify with verify_api.py
```

### Training Workflow
```
1. python run_training.py
2. Models train for all 43 states
3. Forecasts generated (56 days each)
4. Results saved to outputs/
5. API loads forecasts automatically
```

### Deployment Workflow
```
1. Verify all systems working
2. Copy project to production server
3. Install dependencies: pip install -r requirements.txt
4. Start API: python -m uvicorn app.main:app --workers 4
5. Configure reverse proxy (nginx/Apache)
6. Set up monitoring
7. Test endpoints
```
